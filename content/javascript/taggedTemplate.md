前言:
處理字串一直是開發者最主要的核心，人類說著自然的語言，編碼處理結構化的資料，距離很遙遠，因為程式語言並不聰明，它無法把人類的自然語言映射到結構化語言，但是隨著 AI 得出現，這種映射已經不需要開發人員預處理了，更自由，更無縫，js 的 標籤模板(tagged template)與自然語言處理結合的方法可能會成為一種新的編程模式

### 開發人員的角色轉變

我們毋庸置疑是開發人員，但如果我們可以兼職撰稿人(撰稿人)呢
在編碼寫寫文案，發揮我們的創意吧！

```js
const sales = (strings, ...values) => {
	const fullText = String.raw(strings, ...values);
	// 使用AI或規則引擎解析銷售文本
	return {
		context: "sales",
		// 解析後的結構化數據
		data: parseWithAI(fullText),
	};
};
sale`春季特賣會 明星商品${discount}折起，舒芙蕾海綿、絕版刷具、天生激纖長睫毛膏、指甲油任你選!`;
sale`特賣會限定買1送1組，補水柔焦妝前精華/透潤淨白買3送1快來選購吧~`;
```

不管你是技術或非技術人員，都看得懂，非常棒！

### 總結:

我認為編碼模式會隨著 AI 成熟而有不同，編程人員會有多重身份而不只有 coding，編碼更共通因為不管是技術或非技術，都看得懂，交流只需要用自然的語言就夠了，這種無縫，自由將重碩編碼世界
