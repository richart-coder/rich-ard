### 前言:

變數是所有語言的核心概念，定義在哪決定了如何使用它，當你站在內部某個位置看外面，你會發現很多東西看得更清楚了，但當你從外部看內部卻什麼也看不到，這種單一方向的設計，使得具有封裝、私有、閉包 三種特性，這也體現了函數式編程（Functional Programming）的重要概念

### 程式碼範例:

```python
# 封裝、私有、閉包
def run_once(fn):
  done = False
  def wrapper(*args, **kwargs):
    # here: "記得"它被定義時的作用域環境。這就是所謂的「詞法作用域」(Lexical Scope)：
    nonlocal done
    if not done:
      done = True
      return fn(*args, **kwargs)

    # done 成為自由變數 -> 被「回傳的函式」 實際「使用」變數 -> 避免必要的記憶體使用
    return wrapper
```

### 總結:

Python 的作用域（Scope）設計展現了程式語言中優雅的變數管理方式。當我們談論作用域時，最引人注目的是它的單向可見性設計：內層作用域能夠看到外層的變數，但外層作用域卻無法窺探內層的變數內容。這種單向的設計不僅實現了封裝和私有化，更確保了數據的安全性和可控性。
在這個設計中，更迷人的是詞法作用域（Lexical Scope）的概念。函式能夠記住它被定義時的環境，就像是帶著一個「記憶」的容器。即使函式離開了它最初被定義的地方，它依然能夠訪問那些原始環境中的變數，這正是閉包（Closure）機制的核心所在。
特別值得一提的是 Python 的變數捕獲機制。要成為自由變數，需要同時滿足兩個條件：函式必須離開它的原始作用域（通常是通過回傳），且變數必須在內部函式中被實際使用。這種精確的捕獲機制確保了只有必要的變數會被保留，有效地優化了記憶體的使用。
這些特性不僅僅是語言設計的選擇，更體現了函數式編程的核心思想：良好的封裝性、不可變性和狀態管理。通過這些機制，Python 為開發者提供了一個既優雅又高效的變數作用域系統。
