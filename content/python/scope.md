### 前言:

變數是程式語言的核心，而它的作用域決定了使用方式。當你站在內部往外看，世界清晰可見；從外部看內部，卻是一片模糊。這種單向設計賦予了程式三個重要特性：封裝、私有和閉包，也體現了函數式程式設計的精髓。

### 程式碼範例:

```python
# 封裝、私有、閉包
def run_once(fn):
  done = False
  def wrapper(*args, **kwargs):
    # here: "記得"它被定義時的作用域環境。這就是所謂的「詞法作用域」(Lexical Scope)：
    nonlocal done
    if not done:
      done = True
      return fn(*args, **kwargs)

    # done 成為自由變數 -> 被「回傳的函式」 實際「使用」變數 -> 避免必要的記憶體使用
    return wrapper
```

### 總結:

- Python 的作用域展現了優雅的變數管理。它的單向可見性讓內層能看到外層變數，外層卻無法窺探內層，實現了封裝和私有化。
- 詞法作用域使函式能記住定義時的環境。即使離開原始位置，也能存取原環境中的變數，這就是閉包機制。
- 變數捕獲需要兩個條件：函式離開原始作用域且實際使用該變數。這種精確的機制優化了記憶體使用。
- 這些設計體現了函數式程式設計的思想：封裝性、不可變性和狀態管理，為開發者提供了高效的變數作用域系統。
