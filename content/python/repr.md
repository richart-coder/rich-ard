### 前言:

**repr** 在 Python 中不只是一個簡單的字串表示方法，它是一個強大的開發工具。它的設計初衷雖然是為了除錯，但其"可執行的程式碼字串"格式，提供了一種在執行時自動與原始碼進行對照的機制。

### 1. 我們先來看內建的類別，它是如何寫 **repr** 格式

![REPL](/images/repl-datetime_repr.png)

### 2. 當開發者為一個類別實作 **repr** 時，等同於定義了這個類別在開發過程中的"契約"：

```python
def process_admin_task(user):
    if user.role != 'admin':
        # here: 你會知道實例是如何建造的
        raise ValueError(f"需要管理員權限，但收到的是 {user}")


users = [
    User(1, "小明", "user"),
    User(2, "小華", "admin"),
    User(3, "小李", "user")
]

```

#### 這種模式不僅僅是為了除錯，更重要的是：

1. 程式碼即文件：**repr** 輸出的就是建立物件的程式碼
2. 自動驗證：執行時立即知道物件狀態是否符合預期
3. 快速重現：可以直接複製輸出來重建測試案例

### 總結:

**repr** 建立了開發者和程式之間的共通語言，讓我們能在開發初期就定義好物件的標準樣貌，在執行過程中自動檢驗是否符合這個標準。這個看似簡單的機制，實際上體現了"明確勝於隱晦"的 Python 設計哲學，並為整個開發流程帶來了更高的效率和可靠性。
