### 前言:

物件是常用放資料的地方，它有自己的結構，不連續分散，所以找起來不需要一個一個找，可以很動態也可以很靜態，取決你是如何定義的，大多數的場景都是靜態定義的，例如模型的 schema，應用層的狀態，I/O 結構，配置物件，只有少部分需要動態擴展，例如緩存，這種無法事先定義鍵的情況最適合，這也是為什麼類型定義非常重要的原因

#### 1. 大多數應用欄位都會事先知道，提升程式碼可讀性和維護性

```python
   # 使用者的欄位可以事先定義
   from dataclasses import dataclass
   from typing import Literal
   @dataclass
   class User:
      # 應該把所有欄位都定義在這
      name: str
      age: int
      role: Literal["user", "admin"]

   user = User(name="Kyle", age=20, role="admin")
   # (x) user.password = 123
```

#### 2. 型別檢查和 IDE 支援

- 明確的欄位定義讓 IDE 可以提供更好的自動完成功能
- 型別檢查器可以在編譯時就發現潛在的錯誤，而不是等到執行時才發現

#### 3. 資料結構的一致性：

- 確保所有 User 實例都有相同的資料結構
- 避免某些實例有額外的屬性而其他實例沒有，導致行為不一致

### 總結:

這些原因都指向一個核心理念：讓程式碼更容易理解、維護和測試。只有在像緩存這樣真正需要動態擴展的特殊場景，才考慮使用動態欄位。
