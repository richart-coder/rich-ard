## 前言:

MCP 全名叫 model context protocol，有能力無縫整合了 LLM 應用程式和第三方應用程式(可能是資料來源，工具)，以前齁都是 client agent 去做請求，然後服務端做出回應，現在可以把 client agent 替換成 AI agent or 在 client agent 與 應用程式層插入一層 AI agent，今天來討論後者(與 web 開發有關)如何衝擊網站開發

## 傳統：表單介面

```
姓名*: [文本框]
電話*: [文本框]
日期*: [日期選擇器]
時間*: [時間選擇器]
人數*: [下拉菜單]
特殊要求: [文本區域]
```

### 這個 HTML 表單在提交時會轉換為以下結構化數據格式進行傳輸：

```js

{
  "name": "王小明",
  "phone": "0912345678",
  "date": "2025-03-15",
  "time": "19:00",
  "guests": 4,
  "specialRequests": "需要一張兒童椅"
}
```

## MCP 如何衝擊 UI 的設計：對話介面

```html
[大型文本區域] 請告訴我您的預訂需求
```

使用者：「我想為下週五晚上 7 點 4 人用餐外加一個小朋友，我叫王小明，電話是 0912345678」
AI: 需要兒童椅？
使用者：yes
AI: 訂位成功

AI agent 在內部會自動把人類自然語言轉成 API 規格，然後等待回應，agent 收到 server 回應後再轉回自然語言，提升了使用者體驗

## 總結:

MCP 帶來的改變 1.傳統表單 → 對話介面：從限制性輸入到自由表達 2.使用者體驗提升：不再受限於預定義欄位和格式 3.開發重點變化：前端注重對話設計，後端維持原有 API 結構
但這只是冰山一角，MCP 將是下一時代的核心，就像上一代的 HTTP。
